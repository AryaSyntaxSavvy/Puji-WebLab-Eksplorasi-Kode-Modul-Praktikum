Pertemuan 5 & 6: Evaluasi Nilai Belajar (IF-ELSE)

Kalkulasi nilai akhir berbobot (Kuis 30% + Tugas 70%) dengan penentuan predikat IP menggunakan logika percabangan.

JAVASCRIPT CODE
1
2
3
4
5
6
7
function hitungIPK(kuis, tugas) {
  var na = (0.3 * kuis) + (0.7 * tugas);
  if (na >= 80) return "A (Sangat Baik)";
  else if (na >= 65) return "B (Baik)";
  else if (na >= 50) return "C (Cukup)";
  else return "E (Tidak Lulus)";
}

LOGIKA & PENJELASAN

  • 0.3 * kuis: Perhitungan bobot 30% untuk komponen kuis.
  • 0.7 * tugas: Perhitungan bobot 70% untuk komponen tugas.
  • if / else if: Seleksi kondisi bertingkat menentukan nilai mutu A, B, C, atau E.

Pertemuan 8: Dialog Pop-Up JavaScript

1
2
3

  alert("Selamat Datang di World 2!");
}

LOGIKA & PENJELASAN

  • prompt(): Membuka kotak pengisian teks interaktif.
  • confirm(): Pilihan konfirmasi logis OK (True) atau Batal (False).
